The **Biiriize Hanney Alphabet** (abbreviated internationally as the **BI-H/GH script**) is a modern alphabetic writing system. It is designed to provide a simple, consistent, and efficient method for writing African languages—particularly Zarma, Songhai, Dendi, Hausa, Fulani, Tuareg, and Gourmantche.

This repository hosts the first official version of the font using the Biiriize Hanney Alphabet.
